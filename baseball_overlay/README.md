# 少年野球 試合動画テロップ

八幡浜ジュニアベースボールクラブの試合動画に、中継風のテロップを焼き込むための道具一式です。
動画・写真はリポジトリに入れません（ギガファイル便などで受け渡し）。

## デザイン

**標準は「パワプロ風」（`style_kit.py` の `pop` テーマ）。** 2026-11-15 に決定。

| テーマ | 中身 |
|---|---|
| `pop`（標準） | 濃紺パネル＋オレンジ見出し＋白い札、角丸。パワプロ風 |
| `metal` | 黒パネル＋赤見出し＋銀の札、斜め。プロスピ風 |
| 紺×金（旧） | `telop.py` / `scoreboard.py` / `telolib.py` の旧デザイン。2026-10〜11 の納品物で使用 |

## ファイル

| ファイル | 役割 |
|---|---|
| `style_kit.py` | テーマ付きテロップ：対戦カード `matchup`、守備位置 `defense`、選手交代 `change`、スタメン紹介 `lineup` |
| `pop_style.py` / `metal_style.py` | 左上の点数表示 `scoreboard()` と、顔写真枠つき打者テロップ `batter()` |
| `telolib.py` | 選手の氏名表（`FULL`）、守備位置名（`POS`）、旧デザインの打者・守備・交代テロップ |
| `telop.py` | 旧デザインの対戦カード（アニメーション付き、`frames` で連番出力） |
| `scoreboard.py` / `scoreboard2.py` | 旧デザインの点数表示 |
| `lineup_card.py` | 旧デザインのスタメン紹介 |
| `encode_game.sh` | 元動画（MTS）を結合し、全テロップを焼き込んで MP4 を書き出す |
| `splice_overlays.sh` | 完成 MP4 の一部区間だけ再エンコードしてテロップを追加（コマ数を保ったまま差し替え） |
| `gf_up.sh` | ギガファイル便へ100MBずつ分割アップロード（`gf_up.sh <file> 77.gigafile.nu 30`） |
| `metric.py` / `redmetric.py` | 映像の色から攻守交代の時刻を推定する補助 |
| `games/` | 2026年の試合ごとのデータ（スコア推移・打席時刻・相手打者・交代）。次回の入力例 |
| `games/gC.py` | 2026-11-21 立花戦。パワプロ風（pop）一式を作る例：得点イベントと攻守交代から点数表示を自動生成 |
| `fonts/` | Noto Sans JP / Noto Serif JP Black（SIL OFL 1.1、`fonts/OFL.txt`） |

## 使い方の流れ

1. 作業フォルダを決め、`OVERLAY_WORK=/path/to/work/` を設定（未設定ならこのフォルダ）。
2. `games/gen_games.py` を参考に、試合ごとの
   - `states`：点数表示の切り替え（開始秒, 終了秒, 回, top/bottom/final, 先攻点, 後攻点）。**得点は1点ずつ、入った時刻で区切る**
   - `pas`：八幡浜の打席（開始秒, 打順, 選手キー, 守備位置, 第何打席, それまでの結果）
   - `defense`：最初の守備位置と表示秒
   を書いてテロップ画像を作る。相手打者・交代は `games/gA_opp.py` `games/gA_extra.py` の形式。
3. `bash encode_game.sh <試合フォルダ> <出力.mp4> 00002.MTS 00003.MTS ...`
   - `CUT=秒` で末尾をカット。`TEST="-ss 秒 -frames:v 1"` で1コマだけ確認。
4. 確認用の静止画を抜いてチェック → `gf_up.sh` でアップロード。

## 決まりごと

- 一塁側・三塁側はユーザーの指定どおり。対戦カードは左に八幡浜。
- 打者テロップの下段は「第N打席　それまでの結果」（その打席の結果は出さない）。全打席に、その時点の守備位置を出す。
- 打率は出さない（2026-11-07 以降）。
- 相手チームの選手は顔写真なし。
- 元動画は手元から消えることがあるため、修正が多そうなら元動画を消さずに残す。
