# 八西CATV オリジナルAIアニメ 「ころころ、みかん。」

段々畑から転がり落ちたみかんを追いかけた少女ハルが、港で漁師と出会い、みかんを分け合う——
八幡浜の「山（みかん）と海（港）」をつなぐ、60秒のオリジナル短編アニメです。

**完成版: [korokoro_mikan.mp4](korokoro_mikan.mp4)**（1920×1080 / 29.97p / 60秒 / −24 LKFS / テロップ入り）

## 作り方の方針

有料の動画生成AI（Runway など）は使わず、**AI（Claude）が書いたプログラムで1コマずつ絵を描いて**作っています。

| 要素 | 作り方 | 費用 |
|---|---|---|
| 作画・アニメーション | Python + cairo でキャラ・背景を描画（`render/`） | 無料 |
| BGM | プログラムで作曲・音を合成したオリジナル曲（外部音源なし） | 無料 |
| 効果音・環境音 | プログラムで合成（みかんが跳ねる音、足音、波、風） | 無料 |
| 声 | Open JTalk の合成音声（**仮ボイス**） | 無料 |
| テロップ・書き出し | ffmpeg | 無料 |

すべて手元のパソコンで再生成でき、絵や動きの修正はコードを直して `./make.sh` するだけです。

## 作り直し方

```bash
pip install pycairo numpy pyopenjtalk   # 初回のみ（ffmpeg も必要）
./make.sh            # → out/master.mp4（約2分）
./make.sh --mxf      # → 局搬入用 out/master.mxf（MPEG-2 4:2:2 50Mbps / PCM 24bit）も
./make.sh --clean    # → テロップ無し版 out/clean.mp4 も
```

- 一部のカットだけ直したいとき: `python3 render/render.py S06` → `BGM_VOL=0.4 ./assemble.sh`
- 静止画で確認: `python3 render/preview.py check.png S06:1.0,S06:3.0`

## 声を差し替える（放送前に推奨）

いまの声は機械の合成音声（仮）です。放送では**地元の方や局アナウンサーの声**に差し替えるのがおすすめです。

1. 下の時間に合わせて録音し、60秒の `audio/voice.wav`（48kHz）にまとめる
2. `render/voice_timing.json` の `start` と `dur`（口パクの時間）を録音に合わせて直す
3. `KEEP_VOICE=1 ./make.sh` で作り直す（合成音声で上書きせず、録音を使ってBGMの音量調整もやり直します）
