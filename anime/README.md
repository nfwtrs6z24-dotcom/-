# 八西CATV オリジナルAIアニメ 「ころころ、みかん。」

段々畑から転がり落ちたみかんを追いかけた少女ハルが、港で漁師と出会い、みかんを分け合う——
八幡浜の「山（みかん）と海（港）」をつなぐ、60秒のオリジナル短編アニメです。

| ファイル | 内容 |
|---|---|
| [storyboard.md](storyboard.md) | 企画・台本・絵コンテ（カット表）・カット別のAI生成プロンプト・音の設計・30秒版 |
| [characters.md](characters.md) | キャラクター／美術設定と、設定画（リファレンス）用プロンプト |
| [shots.csv](shots.csv) | カット番号と尺（編集の正） |
| [telop.ass](telop.ass) / [telop.srt](telop.srt) | セリフ・NA・タイトルのテロップ（既存テロップと同じ IPAゴシック／縁取りスタイル） |
| [vconte_preview.mp4](vconte_preview.mp4) | 仮カード＋テロップの60秒Vコンテ（クリップ無しで書き出したもの） |
| [assemble.sh](assemble.sh) | 生成クリップ＋音声を並べて放送用マスターを書き出すスクリプト |

## 制作の流れ

1. **設定画を作る** — `characters.md` のプロンプトで、ハル・じいちゃん・漁師・みかん・背景3枚を画像生成。気に入った1枚ずつを `refs/` に保存。
2. **Vコンテで尺を確認** — クリップが無い状態で `./assemble.sh` を実行すると、カット番号と内容を書いた仮カード＋テロップの60秒動画（`out/master.mp4`）ができます。ナレーションを仮録りして `audio/voice.wav` に置けば、間（ま）の確認ができます。
3. **各カットを生成** — `storyboard.md` の「画像プロンプト」で1フレーム目を作り、設定画を参照させつつ「動画プロンプト」で Image to Video（Runway など）。1カットにつき数本生成して良いものを選び、`clips/S01.mp4`〜`S10.mp4` に保存。
4. **音を入れる** — セリフ・NAを60秒タイムラインに並べた `audio/voice.wav`、BGM `audio/bgm.wav` を置く。
5. **書き出し** — `./assemble.sh --mxf --clean`
   - `out/master.mp4` … 1920×1080 / 29.97p / テロップ焼き込み / −24 LKFS
   - `out/clean.mp4` … テロップ無し版
   - `out/master.mxf` … MPEG-2 4:2:2 50Mbps / PCM 24bit（局のサーバー搬入用の叩き台）
6. **放送前チェック**（下記）→ 局内試写 → 搬入

クリップは長さ・解像度・フレームレートがバラバラでも、スクリプトが 1920×1080・29.97p・指定尺にそろえます（短い場合は最終フレームで延長）。
細かい編集（ディゾルブ、SEのタイミング調整など）は、`out/clean.mp4` を普段の編集ソフトに読み込んで仕上げても構いません。

## 放送前チェックリスト

**技術**
- [ ] 局の搬入仕様（解像度 1920/1440、フレーム 59.94i/29.97p、コーデック、ファイル形式）と `out/master.mxf` の設定を照合した
- [ ] 音声ラウドネス −24 LKFS（ARIB TR-B32）。スクリプト最後に表示される `I:` の値で確認
- [ ] 尺がちょうど60秒（枠の前後に黒・無音が必要なら局の指定に合わせる）
- [ ] テロップがセーフエリア内、誤字なし

**表現（光過敏性発作の防止）**
- [ ] 「アニメーション等の映像手法に関するガイドライン」（NHK・民放連）に沿い、1秒に3回を超える点滅・急激な明暗変化・赤の点滅・規則的な縞模様がない。AI生成の**夕日の水面のキラキラ、ちらつき（フリッカー）**は特に注意

**AI・権利**
- [ ] 使用した画像／動画／音声生成AIの利用規約で、**商用・放送利用が許可**されたプランで生成した
- [ ] 既存アニメ・キャラクターに似すぎていない（プロンプトに既存作品名・作家名を入れていない）
- [ ] 実在の人物の顔、実在店舗の看板・ロゴ、船名などが写り込んでいない
- [ ] BGM・効果音・ナレーション音声の放送利用権を確認した
- [ ] 「映像の一部に生成AIを使用しています」の表記を入れた（タイトルカットに入れ済み）
- [ ] AIのみで生成した部分は著作権が認められにくい点に留意し、台本・絵コンテ・編集など人の創作部分の記録（このリポジトリ）を残した

## メモ
- テロップの見た目は既存の `telop/telop.ass`（1440×1080・横75%）を 1920×1080 に換算したものです。
