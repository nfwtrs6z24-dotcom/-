# 八西CATV オリジナルAIアニメ 「ころころ、みかん。」

段々畑から転がり落ちたみかんを追いかけた少女ハルが、港で漁師と出会い、みかんを分け合う——
八幡浜の「山（みかん）と海（港）」をつなぐ、60秒のオリジナル短編アニメです。

**完成版: [korokoro_mikan.mp4](korokoro_mikan.mp4)**（1920×1080 / 29.97p / 60秒 / −24.5 LKFS / テロップ入り）

## 作り方の方針

有料の動画生成AI（Runway など）は使わず、**AI（Claude）が書いたプログラムで1コマずつ絵を描いて**作っています。

| 要素 | 作り方 | 費用 |
|---|---|---|
| 作画・アニメーション | Python + cairo でキャラ・背景を描画（`render/`） | 無料 |
| 演出・撮影処理 | 陰影とリムライト、接地影、光の筋、水面のきらめき、モーションブラー、背景ぼかし、光のにじみ、フィルムグレイン | 無料 |
| BGM | プログラムで作曲・音を合成したオリジナル曲（外部音源なし） | 無料 |
| 効果音・環境音 | プログラムで合成（みかんが跳ねる音、足音、波、風、場面転換、チャイム） | 無料 |
| 声 | Open JTalk の合成音声（**仮ボイス**）。女性の声は HTS Voice "Mei"（CC BY 3.0） | 無料 |
| 文字 | Zen Maru Gothic（SIL Open Font License） | 無料 |
| テロップ・書き出し | ffmpeg | 無料 |

### 見どころ（演出）

- **S03** みかんが滑る瞬間の集中線 → ハルのびっくり顔のアップ →「きりっ」として走り出す
- **S04** 段々畑の追いかけっこ: モーションブラー、着地のつぶれ・砂ぼこり・画面ゆれ、スピード線
- **S05→S06** みかん色の円が画面をおおって港の場面へ（ワイプ）
- **S07** 背景をぼかして人物を引き立てる（被写界深度）、夕方のリムライト
- **S08→S09** ハルが空にかざしたみかんが画面いっぱいに広がり、そのまま**夕日になる**
- **S10** 転がるみかんが通りすぎると文字が1つずつ跳ねて現れ、みかんが句点「。」になる

## 作り直し方

```bash
pip install pycairo numpy pillow pyopenjtalk   # 初回のみ（ffmpeg も必要）
./make.sh            # → out/master.mp4（4コアで約10分。高画質マスター 約230MB）
./make.sh --mxf      # → 局搬入用 out/master.mxf（MPEG-2 4:2:2 50Mbps / PCM 24bit）も
./make.sh --clean    # → テロップ無し版 out/clean.mp4 も
```

- 一部のカットだけ直したいとき: `python3 render/render.py S06` → `BGM_VOL=0.4 ./assemble.sh`
- 静止画で確認: `python3 render/preview.py check.png S06:1.0,S06:3.0`

## 声を差し替える（放送前に推奨）

いまの声は機械の合成音声（仮）です。放送では**地元の方や局アナウンサーの声**に差し替えるのがおすすめです。

1. 下の時間に合わせて録音し、60秒の `audio/voice.wav`（48kHz）にまとめる
2. `render/voice_timing.json` の `start` と `dur`（口パクの時間）を録音に合わせて直す
3. `KEEP_VOICE=1 ./make.sh` で作り直す（合成音声で上書きせず、録音を使ってBGMの音量調整もやり直します）

## メモ
- テロップは丸ゴシック（Zen Maru Gothic）にしています。局の標準書体に合わせる場合は `telop.ass` の Fontname を変えてください。
- `storyboard.md` の英語プロンプトは、将来、画像・動画生成AIで作り直す場合の参考として残しています。
- `out/`（MXF 約390MB など）はサイズが大きいため Git には入れていません。必要なら Releases に置いてください。
