# 01 市場調査：500円noteテーマ10案（社員① 市場調査担当）

ジャンル：少年野球　／　調査日：2026-11-10

## 調査方針
「売れている記事を真似する」のではなく、**既存の記事を読んでも解決しきれていない悩み**を探した。各テーマは次の4条件で絞り込んでいる。
- 半年〜1年後も需要がありそう
- 初心者でも実践できる
- 1つの具体的な悩みを解決できる
- 4,000字程度で完結する

表記ルール：
- **［確認］**：Web検索で根拠を確認できた情報（出典は末尾）
- **［推測］**：Webで確認できず、推測や一般論にもとづく情報

> 注意：note.com内の有料記事（価格・販売数・スキ数）は検索ツールで取得できなかった。競合欄はWebメディア・書籍・アプリが中心で、note上の競合は**すべて［推測］**。販売前にnote内で「少年野球 ＋ テーマ語」を検索して確認すること。

## テーマ1：試合後の「帰りの車」での声かけ
| 項目 | 内容 |
|---|---|
| 想定読者 | 小学生の野球少年の父母。試合を見ると熱くなりやすい人 |
| 悩み | 帰りの車で反省会をしてしまい、子どもが黙り込む。何と言えばいいか分からない |
| 競合 | ［確認］現代ビジネス・文春オンライン・プレジデントなどの「叱るより認める」系の記事。［確認］英語圏にも「試合後の車内のダメ出し」を扱う寄稿がある |
| 既存記事で解決していない点 | ［確認］考え方は語られているが、場面別の具体的なセリフまで落とし込んだ記事は見つからなかった |
| 差別化ポイント | 勝った日／負けた日／エラーした日などの場面別セリフ、NGワードの言い換え表 |
| 長期需要 | 毎週末の試合で繰り返し起きる悩みなので、季節を問わない |

## テーマ2：入団前のチーム見学で「親の負担」と「指導方針」を見抜く質問リスト
| 項目 | 内容 |
|---|---|
| 想定読者 | 年長〜小学低学年の子が野球を始めたいと言い出した親。野球未経験者が多い［推測］ |
| 悩み | どのチームに入ればいいか分からない。入ってから当番の重さや厳しい指導を知るのが怖い |
| 競合 | ［確認］コエテコ、BASEBALL KING、るるぶキッズに「チーム選びのポイント」記事がある（指導者の資質、方針の相性、当番の有無など） |
| 既存記事で解決していない点 | ［確認］「見学で確認しよう」とは書いてあるが、［推測］**見学当日に誰に何をどう聞けば角が立たないか**という具体的な質問文まではない |
| 差別化ポイント | 見学時にそのまま使える質問文20個、観察チェック表、2チームを比べる採点シート |
| 長期需要 | 毎年春の入団シーズンに必ず需要がある。ピークは1〜4月［推測］ |

## テーマ3：初めての「保護者審判」で慌てないための準備
| 項目 | 内容 |
|---|---|
| 想定読者 | 練習試合の塁審を突然頼まれた父親（母親）。ルールにあまり詳しくない |
| 悩み | 判定を間違えて試合を壊したらどうしよう。立つ位置もジェスチャーも分からない |
| 競合 | ［確認］NPBの初心者審判向けリーフレット、審判入門の書籍（2021年発売）、BASEBALL KINGの記事 |
| 既存記事で解決していない点 | ［確認］ルール全般を扱う本はあるが、［推測］「練習試合の塁審を1試合こなす」ことに絞った最低限のガイドは少ない |
| 差別化ポイント | 塁審だけに絞った「これだけ覚えればいい」リスト、迷ったときの対処、当日の持ち物 |
| 長期需要 | ［確認］学童野球では審判が不足しがちで、毎年新しい保護者が担当することになる |

## テーマ4：初めての「スコア係」で当日困らない最低限のつけ方
| 項目 | 内容 |
|---|---|
| 想定読者 | スコア係を任された野球未経験の保護者 |
| 悩み | 記号が多すぎて覚えられない。試合のスピードに追いつけない |
| 競合 | ［確認］NPB監修の入門書（2020年刊）、ルールブック、スコアアプリ（スコアブック、SmartScorer、bb-score など） |
| 既存記事で解決していない点 | ［推測］本は網羅的で、「最初の1試合で必要な分だけ」を絞ったものが少ない |
| 差別化ポイント | 最初に覚える記号を10個に絞る、よくある場面の書き方の早見表 |
| 長期需要 | 毎年、新しい担当者が生まれる。ただし本とアプリが強い |

## テーマ5：お茶当番・係の負担を「角を立てずに」見直す提案の仕方
| 項目 | 内容 |
|---|---|
| 想定読者 | 当番の負担に悩む共働きの保護者、保護者会の役員 |
| 悩み | 負担を減らしたいが、言い出すと孤立しそうで怖い |
| 競合 | ［確認］Number、livedoor、現代ビジネスで問題提起の記事が多い。［確認］当番の軽減を提案して嫌がらせを受けたという体験談もある。［確認］当番を「ケア当番」に変えた埼玉のチームの事例がある |
| 既存記事で解決していない点 | ［確認］問題提起が中心で、**どう提案すれば通るか**という手順まで扱う記事は見つからなかった |
| 差別化ポイント | 提案の順番（誰に・いつ・どう言うか）、保護者会で配る提案書テンプレート、反対意見への返し方 |
| 長期需要 | ［推測］当番をなくすチームが増えると需要が減る可能性がある。一方で、地域差が大きく当面は残りそう |

## テーマ6：中学で「部活の軟式」か「クラブの硬式」か、親子で決める判断シート
| 項目 | 内容 |
|---|---|
| 想定読者 | 小学5〜6年生の野球少年の親 |
| 悩み | どちらを選べばいいか分からない。費用・送迎・将来への影響を比べたい |
| 競合 | ［確認］BASEBALL KING、現代ビジネスの記事、大学の研究論文、日本野球協議会の調査（2025年）など情報が多い |
| 既存記事で解決していない点 | ［推測］情報はあるが、**自分の家庭の場合にどう判断するか**に落とし込むツールがない |
| 差別化ポイント | 家庭の条件（費用・送迎・本人の目標）を記入するだけで比べられる判断シート |
| 長期需要 | 毎年の進路の時期に必ず需要がある。ただし悩みの深さに比べて、競合の情報量が多い |

## テーマ7：スマホで子どもの投球・打撃フォームを撮って比べる方法
| 項目 | 内容 |
|---|---|
| 想定読者 | 家で自主練に付き合っている親。野球経験が少ない人も含む |
| 悩み | フォームの何が悪いのか分からない。動画を撮っても見方が分からない |
| 競合 | ［確認］東京都のスポーツドリル資料（三脚で固定、グリッド線の活用など）。［確認］AIでフォームを解析するアプリが複数ある |
| 既存記事で解決していない点 | ［推測］撮り方の一般論とアプリ紹介はあるが、**同じ条件で撮り続けて成長を比べる仕組み**を親向けにまとめたものが少ない |
| 差別化ポイント | 撮影位置の固定ルール、比較用の並べ方、月1回の記録テンプレート |
| 長期需要 | 季節を問わない。ただしAIアプリの進化で価値が下がる可能性がある［推測］ |

## テーマ8：保護者がスマホで作る「卒団ムービー」完全手順
| 項目 | 内容 |
|---|---|
| 想定読者 | 卒団ムービー係になった6年生の保護者。動画編集の経験がほぼない |
| 悩み | 何から始めればいいか分からない。写真が集まらない。締め切りに間に合うか不安 |
| 競合 | ［確認］少年野球の卒団ムービーの作り方を解説したページは検索でほとんど見つからなかった。［確認］見つかったのは、結婚式・卒園向けのアプリ紹介記事と、外注の依頼事例（5〜10分のムービーを予算2〜3万円で依頼した例） |
| 既存記事で解決していない点 | ［確認］**写真の集め方（保護者への依頼方法）と、個人情報への配慮**を扱う情報は検索で見つからなかった。［推測］卒団式から逆算したスケジュールの立て方もほぼない |
| 差別化ポイント | 写真募集の依頼文テンプレート、逆算スケジュール表、構成表（尺の配分）、上映当日のチェックリスト |
| 長期需要 | 毎年の卒団式（多くは2〜3月［推測］）で必ず需要がある。季節性は強い |

## テーマ9：部員が集まらないチームのための「部員募集動画」をスマホで作る
| 項目 | 内容 |
|---|---|
| 想定読者 | 部員不足に悩むチームの保護者・指導者。広報係 |
| 悩み | 部員が減っている。チラシだけでは人が来ない |
| 競合 | ［確認］少年野球の競技人口が減っていることは、笹川スポーツ財団の資料や東洋経済の記事で報じられている。［推測］募集動画の作り方に特化した記事はほぼない |
| 既存記事で解決していない点 | ［推測］「体験会に来てもらう」ための動画の構成（何を見せると親が安心するか）がない |
| 差別化ポイント | 30秒動画の構成テンプレート、親が安心するポイント（当番・費用・雰囲気）の見せ方、SNS投稿時の注意点 |
| 長期需要 | 部員減少が続く限り需要は続く［推測］。ただし読者（広報係）の母数は小さい |

## テーマ10：初めてのグローブ選びで失敗しないサイズと硬さの選び方

|---|---|

| 既存記事で解決していない点 | ［推測］無料記事でほぼ解決できるため、未解決の悩みは少ない |
| 差別化ポイント | 店頭で確認する手順のチェックリスト（差別化の余地は小さい） |
| 長期需要 | 毎年あるが、無料情報で満たされている |

## あなたの経験を活かせるテーマ3案

> 前提［本人確認済み］：**会社で動画の撮影・編集をしている。**（当初はリポジトリのテロップファイルからの推測だったが、本人に確認した）

| 順位 | テーマ | 経験が活きる理由 |
|---|---|---|
| 1 | **テーマ8：卒団ムービー完全手順** | 編集の手順、尺の配分、テロップの入れ方、書き出し設定など、実務経験がそのまま記事の具体性になる。競合がほぼいない |
| 2 | テーマ9：部員募集動画 | 短い動画で「伝わる構成」を作る経験が活きる。地域向け動画の経験（図書館の紹介動画）とも近い |
| 3 | テーマ7：フォーム動画の撮り方 | 撮影位置・画角・比較編集のノウハウが活きる。ただしAIアプリとの差別化が必要 |
