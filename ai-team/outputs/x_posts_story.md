# X投稿：感動系の話（案）

- A：あなたの実際の考え方（みんなを映す／喜ばれるとやる気）にもとづく投稿。そのまま投稿できる
- C：創作の話。必ず「#創作」を付けたまま投稿する（実話として投稿しない）
- B：実話テンプレート。あなたや知人の本当の出来事を【】に入れて使う

## A1（98字）
```
動画を作るとき、いつも大事にしていることがあります。

みんなを、ちゃんと映すこと。

ホームランを打った子も、
ベンチで最後まで声を出した子も。

見ている家族にとっては、
どの子も主役だから。
```

## A2（72字）
```
動画編集は、ひとりで黙々と続ける地味な作業です。

でも、見た人に
「ありがとう」
と言われた瞬間、全部報われる。

だから、また作りたくなる。
```

## C1（113字）
```
卒団ムービーの写真集め。

ある子だけ、試合中の写真が1枚もなかった。
6年間、ほとんどベンチだったから。

でも届いたのは、ベンチから身を乗り出して声を出す写真が30枚。

撮っていたのは、その子のお父さんだった。

#創作
```

## C2（105字）
```
卒団式のムービーで、一人ずつ名前が出る場面。

最後に映ったのは、選手じゃなかった。

6年間、毎週誰よりも早く来て、グラウンドを整備してくれていたOBのおじいさん。

会場で一番大きな拍手が起きた。

#創作
```

## C3（112字）
```
息子が卒団した日の帰り道。

いつもの車の中で、反省会はもうしなかった。

「6年間、楽しかった？」

少し黙ってから、
「お父さんが毎回見に来てくれたのが、一番うれしかった」

運転しながら、前が見えなくなった。

#創作
```

## C4（103字）
```
卒団ムービーのラスト。

入団式の小さな集合写真と、
6年後の集合写真を並べた。

ぶかぶかだったユニフォームが、
いつの間にかぴったりになっていた。

泣いていたのは、子どもより親のほうだった。

#創作
```

## B 実話テンプレート
```
【子どもの名前は出さない：例「チームの6年生」】の卒団式。

【その場面で起きたこと】

【誰かが言った一言／した行動】

【自分がどう感じたか】
```
```
動画を作っていて、一番うれしかったこと。

【誰に見せたか】に見せたとき、
【相手の反応・一言】

【その一言で、自分がどう思ったか】
```
