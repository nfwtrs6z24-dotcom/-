### 帰りの車内が「第2の試合」になっていませんか

「なんであそこで振らなかったの？」
「エラーの後、下向いてたよね」
「〇〇くんはもっと声出してたよ」

試合が終わり、車に乗った瞬間に始まる反省会。気づけば子どもは窓の外を見たまま、何も言わなくなっている。

私もまったく同じでした。【要記入：著者の経験。例「息子が小2で地域チームに入ってから4年間、毎週末グラウンドに通っています」】

言っている最中は「この子のため」と本気で思っています。でも、ある日息子に「車に乗るのがイヤだ」と言われて、ハッとしました。グラウンドで頑張ってきた子にとって、帰りの車は休む場所ではなく、もう一試合だったのです。

調べてみると、同じ悩みを持つ親はとても多いことが分かりました。「叱らずに認めましょう」という記事はたくさんあります。でも、肝心の「じゃあ、帰りの車で具体的に何て言えばいいの？」に答えてくれるものは、ほとんど見つかりませんでした。

だから、自分で試して、うまくいった言葉を集めることにしました。この記事は、その記録です。

### 反省会が逆効果になる3つの理由

**① 子どもは誰よりも自分の失敗を分かっている**
エラーした瞬間、一番悔しいのは本人です。そこに親が重ねて指摘すると、子どもは「失敗＝責められること」と覚えます。すると次の試合で、ボールが飛んでこないように祈るようになります。

**② 試合直後は話を聞ける状態ではない**
体は疲れ、気持ちは高ぶるか沈んでいる。大人でも、大きな失敗をした直後に上司から細かく指摘されたら、内容より「怒られた」という感情しか残りませんよね。

**③ 野球が「親を喜ばせるためのもの」になる**
評価が親の口から毎回出ると、子どもは自分の楽しさより親の顔色でプレーするようになります。少年野球を辞めるきっかけとして、大人の過剰な関わりはよく指摘されています。

では、何を言えばいいのか。
この記事では、毎週末の帰り道ですぐ使えるように、次のことをまとめました。

- 帰り道の会話の「黄金ルール」
- 場面別（勝った／負けた／エラー／出番なし／大活躍／三振）の声かけ実例
- 子どもが何も話さないときの対応と、翌日の「野球ノート」での振り返り
- 夫婦の役割分担
- ついやってしまうNGワードと言い換え表
- 親自身がイライラしたときの感情リセット法
- 「野球やめたい」と言われたときの対応

今週末の試合の帰りから、そのまま使ってください。

### 黄金ルール：「聞く→認める→待つ」の順番を守る

帰りの車内でやることは、たった3つです。

**STEP1 聞く（最初の5分は親から評価しない）**
最初の一言は質問にします。おすすめは「今日、一番楽しかったのはどこ？」。「どうだった？」だと漠然としすぎて、「別に」で終わりがちです。「楽しかった」に限定すると、子どもは良かった場面を自分で思い出します。

**STEP2 認める（結果ではなく行動をほめる）**
「ヒット打ったね」ではなく「最後まで振り切ったね」。結果は運にも左右されますが、行動は子どもが自分で決められます。行動をほめられた子は、次も同じ行動を選びます。

**STEP3 待つ（反省は子どもから言い出すまで待つ）**
「あのエラー、悔しかった」と子どもが言ったら、初めて振り返りのチャンスです。そのときも「どうしたらよかったと思う？」と答えを子どもに出させます。親が答えを言うのは、子どもが聞いてきたときだけ。

ポイントは、**親が話す量を子どもより少なくする**ことです。目安は親3割、子7割。

### 場面別の声かけ実例

**【勝った日】**
✕「今日は勝ったけど、あのエラーは危なかったね」
○「みんなで喜んでたね。〇〇はどの場面が一番うれしかった？」
→ 勝った日にまで課題を言うと、子どもは「何をしても満足してもらえない」と感じます。勝った日は、喜びを一緒に味わう日にします。

**【負けた日】**
✕「なんで負けたと思う？」
○「最後まであきらめてなかったの、ちゃんと見てたよ」
→ 負けの原因探しは、チームの指導者の仕事です。親は「見ていたよ」と伝えるだけで十分です。

**【エラーした日】**
✕「なんであそこで捕れないの」
○「エラーの後の打球、ちゃんと前に出てたね」
→ エラーそのものではなく、「その後どう動いたか」を見て伝えます。失敗から立ち直った行動をほめると、失敗を怖がらなくなります。

**【試合に出られなかった日】**
✕「次は出られるように練習しなきゃね」
○「ベンチから一番声出してたね。あれ、チームの力になってたよ」
→ 出られなかった悔しさは本人が一番感じています。ベンチでの役割を認めると、「自分もチームの一員だ」と思えます。

**【大活躍した日】**
✕「今日は良かったけど、調子に乗らないようにね」
○「打った瞬間、どんな感じだった？」
→ 活躍した日は、子どもに「成功の感覚」を言葉にしてもらうチャンスです。自分で言葉にした感覚は、次の打席の再現につながります。釘を刺す必要はありません。

**【三振した日】**
✕「見逃し三振だけはダメって言ったでしょ」
○「あのピッチャー速かったね。2球目のファウル、タイミング合ってたよ」
→ 相手のすごさを認めつつ、良かった1球を具体的に伝えます。「具体的に見てくれている」と感じると、子どもの信頼はぐっと上がります。

### ついやってしまうNGワード → 言い換え表

| NGワード | 言い換え |
|---|---|
| なんで〇〇しなかったの？ | 〇〇の場面、どう考えてた？ |
| 〇〇くんはできてたよ | 先月より〇〇ができるようになったね |
| もっと声出しなさい | 声が出てた場面、かっこよかったよ |
| 練習しないからだよ | 明日、5分だけ一緒にキャッチボールする？ |
| そんなんじゃレギュラーになれないよ | 〇〇が得意なところ、もっと伸ばそうか |
| 泣くな | 悔しいよね。それだけ本気だったんだね |
| 楽しそうにしてなかったね | 今日はしんどかった？ |
| せっかく見に行ったのに | 今日も見られてうれしかったよ |

言い換えのコツは、「過去の否定」を「未来の提案」か「今の気持ちの代弁」に変えることです。

### 子どもが何も話さないときは

「今日、一番楽しかったのはどこ？」と聞いても、「別に」「疲れた」としか返ってこない日もあります。そんな日は、無理に話させなくて大丈夫です。

- 好きな音楽をかけて、黙って運転する
- 「お疲れさま。コンビニ寄る？」と、野球以外の話をする
- 家に着いたら「今日もよく頑張ったね」とだけ伝える

話さないのは、気持ちを整理している最中のサインです。親が沈黙を受け入れてくれると、子どもは「この車は安心できる場所だ」と感じます。その安心が、次に話してくれるときの土台になります。

### 振り返りは「翌日」に「野球ノート」で

技術的な振り返りをしたいなら、試合当日ではなく翌日以降にします。おすすめは、子ども用の小さなノートを1冊用意すること。

書くのは次の3行だけです。

1. 今日できたこと
2. 次にやってみたいこと
3. 練習で試すこと

親は書かせるのではなく、子どもが書いたら「見せてくれる？」と聞いて読むだけ。赤ペンで直したり、内容に注文をつけたりはしません。自分で書いた目標は、親に言われた目標よりずっと長続きします。

### 夫婦で「役割分担」を決めておく

どちらか一方が熱くなりやすいなら、事前に役割を決めておくと楽になります。

- **技術の話をする係**：子どもから聞かれたときだけ答える
- **気持ちを受け止める係**：帰りの車では必ずこちらが先に話しかける

大事なのは、二人で同時に指摘しないこと。両親から同時に言われると、子どもには逃げ場がなくなります。「今日はどっちが聞き役？」と、出発前に確認しておくだけでも効果があります。

### 親がイライラしたときの感情リセット法

頭では分かっていても、試合を見ていると熱くなるのが親です。私も何度も失敗しました。そんなときのための3つの方法です。

**① 車に乗る前に「自販機タイム」をとる**
グラウンドを出たら、まず飲み物を一本買う。その1〜2分で、親の気持ちを試合モードから家族モードに切り替えます。

**② 言いたいことはスマホのメモに書く**
どうしても伝えたいことは、その場で言わずにメモへ。翌日読み返すと、半分は言わなくていいことだと気づきます。残った半分も、子どもが聞いてきたときに伝えれば十分です。

**③ 「この子の野球人生は、この子のもの」と心で唱える**
親が代わりに打席に立つことはできません。子どもの野球を応援する側に戻るための、自分への合言葉です。

### 「野球やめたい」と言われたら

まず、すぐに説得しないこと。「なんで？」と理由を問い詰めるのも逆効果です。

1. **受け止める**：「そう思うくらい、しんどかったんだね」
2. **理由を分ける**：野球そのものがイヤなのか、人間関係なのか、親の関わりなのかを、時間をかけて聞く
3. **選択肢を出す**：「少し休む」「練習日を減らす」「別のチームを見てみる」など、辞めるか続けるかの二択にしない

実は、理由が「帰りの車がイヤだった」というケースもあります。この記事の声かけを2〜3週間続けてから、もう一度気持ちを聞いてみてください。【要記入：著者の体験があれば追記】

### まとめ：今週末からやること

- 帰りの車の最初の一言は「今日、一番楽しかったのはどこ？」
- 結果ではなく行動をほめる
- 反省は子どもが言い出すまで待つ
- 言いたいことはメモに書き、翌日読み返す

少年野球は、親子で同じ時間を過ごせる貴重な数年間です。帰りの車が「また次も頑張ろう」と思える場所になれば、子どもはきっと野球をもっと好きになります。

この記事が、次の週末の帰り道を少しでも楽にできたら、とてもうれしいです。
