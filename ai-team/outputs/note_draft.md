## 本文

### ① 卒団ムービー係になって、途方に暮れていませんか

「卒団ムービー、お願いできますか？」

役員会でそう頼まれて、断れずに引き受けた。でも、動画なんて作ったことがない。何から始めればいいのか分からないまま、卒団式の日だけが近づいてくる。

- 写真を送ってくださいとお願いしたのに、なかなか集まらない
- 集まった写真が、一部の子に偏っている
- どのアプリを使えばいいのか、何分の動画にすればいいのか分からない
- 当日、会場で再生できなかったらどうしよう

卒団ムービーは、6年間（あるいは数年間）頑張ってきた子どもたちと、支えてきた家族にとって大切な記念になります。だからこそ「失敗できない」というプレッシャーが大きい仕事です。

調べてみると、外注するという選択肢もあります。依頼サイトには、手持ちの写真や動画を使った5〜10分のムービーを、2〜3万円程度の予算で依頼している少年野球チームの例もありました。

でも、予算が限られているチームも多いはずです。そして、スマホ1台でも心に残るムービーを作ることはできます。

私はプライベートで、動画の撮影と編集をしています。この記事では、自分が動画を作るときの段取りを、卒団ムービー向けにまとめました。

### ② 卒団ムービーがうまくいかない本当の原因

卒団ムービー係が苦戦する原因を「編集の技術がないから」だと思っていませんか。

実は、つまずきやすいポイントは**編集の前**にあります。

**原因1：写真集めを「お願い」だけで済ませている**
「写真を送ってください」と声をかけるだけでは、写真はなかなか集まりません。送る側は、どの写真を、何枚、いつまでに、どこへ送ればいいのかが分からないからです。

**原因2：ゴールの形を決めずに作り始めている**
何分の動画にするのか、どんな順番で見せるのか。構成を決めずに編集を始めると、写真を並べるだけで時間が過ぎ、最後に「長すぎる」「この子が少ない」と気づきます。

**原因3：締め切りから逆算していない**
卒団式の前日まで作業していると、確認する人がいない、会場で再生テストができない、といったトラブルに対応できません。

つまり、卒団ムービーの成否は「編集」より**「写真集め」「構成」「スケジュール」の段取り**で決まります。編集アプリの操作は、段取りさえできていれば後からでも覚えられます。

この記事の有料部分では、この段取りを具体的な手順とテンプレートにしました。

**購入すると手に入るもの**
- 卒団式から逆算した「やることスケジュール表」
- そのままLINEで送れる「写真募集の依頼文」テンプレート
- 全員が主役になる「構成表」と「写真の偏りチェック表」
- 今日から始められる5ステップ
- 上映当日のトラブルを防ぐチェックリスト
- 失敗しやすいポイントと、その防ぎ方

### ③ 具体的な解決方法：段取りの3本柱

**柱1：写真は「依頼文」で集める**
送る側が迷わないように、「どの写真を」「何枚」「いつまでに」「どこへ」を1通の依頼文にまとめます。「お子さん以外の子が写っていても大丈夫」と添えておくと、自分の子が写っていない写真も送ってもらいやすくなります。さらに、締め切りの前にリマインドを1回入れる前提で予定を組みます。

**柱2：先に「構成表」を作り、足りない写真を探しに行く**
集まった写真から構成を考えるのではなく、構成を先に決めてから「このパートに足りない写真」を探します。こうすると、写真の偏りに早く気づけます。

**柱3：卒団式から「逆算」して、確認の時間を確保する**
完成の目標日を、卒団式の当日ではなく「1週間以上前」に置きます。その間に、役員や監督に見てもらう時間と、会場での再生テストの時間を確保します。

### テンプレート1：逆算スケジュール表
| 時期（卒団式から逆算） | やること |
|---|---|
| 8週間前 | 役員と相談して、長さ・上映方法・予算・BGMの方針を決める |
| 7週間前 | 写真募集の依頼文を送る |

| 1週間前 | 役員・監督に確認してもらい、修正して完成。会場で再生テスト |
| 当日 | 予備データを持って上映 |

### テンプレート3：構成表
| パート | 内容 | 長さの配分 |
|---|---|---|
| オープニング | チーム名・タイトル・集合写真 | 短め |
| 思い出の時系列 | 入団 → 低学年 → 高学年の順に写真を流す | 長め |
| 一人ずつの紹介 | 選手ごとに写真＋名前＋背番号（＋一言） | 全員を同じ長さに |
| 感謝のメッセージ | 監督・コーチ・保護者への感謝 | 短め |
| エンディング | 最後の集合写真、日付 | 短め |

- 全体の長さは、役員と相談して先に決めておく。私のおすすめは**5〜10分**です。見ている人が飽きずに最後まで見られる長さだからです
- 写真1枚あたりの表示時間 × 枚数 ＝ 全体の長さ、で逆算して、使う枚数を決める
- 1枚あたりの表示時間は、私は**3〜5秒**を目安にしています
  - 計算例：写真100枚 × 3〜5秒 ＝ 300〜500秒（約5分〜8分20秒）
  - 先に長さを決めたら、逆に「使える枚数」が分かります。例えば6分（360秒）なら、1枚4秒で90枚です

### 編集アプリを選ぶ3つの基準
アプリの機能や料金は頻繁に変わるので、特定のアプリを覚えるより、次の3点で選ぶのがおすすめです。

1. **テロップ（文字）を入れやすいか**：一人ずつの紹介パートで名前を入れるため、文字の大きさ・位置・表示時間を簡単に変えられるものを選びます
2. **書き出した動画にロゴ（透かし）が入らないか**：無料版だとロゴが入るアプリもあります。最初に短い動画を書き出して確認します
3. **利用規約で、用途に問題がないか**：個人・非営利の利用に限るアプリもあります。チームの行事で上映する用途に合うかを確認します

迷ったら、まず10秒ほどの試作を作って、書き出しまで通してみてください。最後まで操作できたアプリが、あなたに合ったアプリです。

### ④ 今日から実践できる5ステップ

**STEP1：役員と「4つの方針」を決める（今日）**
長さ、上映方法（プロジェクター／テレビ）、予算、BGMの方針。この4つが決まらないと、後で作り直しになります。

**STEP2：共有アルバムを作り、依頼文を送る（今日〜3日以内）**
送り先は、保護者が使い慣れたLINEのアルバムや共有フォルダにします。テンプレート2をそのまま使ってください。

**STEP3：構成表と偏りチェック表を用意する（1週間以内）**
写真が届き始めたら、テンプレート3・4に枚数を記入していきます。足りない子がいれば、その家庭に個別に声をかけます。

**STEP4：仮編集 → 初稿を作る（2〜3週間）**
構成表の順に写真を並べ、次にテロップ、最後にBGMを入れます。最初から細かい演出にこだわらず、まず最後まで通すことを優先します。
私は、パソコンの編集ソフト（Premiere ProやEDIUS）を使っています。ただ、この記事で紹介している段取り（構成 → 写真を並べる → テロップ → BGMの順）は、どのソフトでも、スマホのアプリでも同じです。パソコンの編集ソフトを持っていない人は、前の「編集アプリを選ぶ3つの基準」でスマホのアプリを選んでください。

**STEP5：確認・再生テスト・予備の用意（卒団式の1週間前まで）**
役員や監督に見てもらい、名前の誤字や写真の抜けを確認します。会場の機材で再生できるかを必ず試し、予備のデータも用意します。

- □ 予備データ（USBメモリ・スマホ本体など、2か所以上）

### ⑤ 失敗しやすいポイント

**失敗1：写真の偏りに最後まで気づかない**
よく撮ってくれる家庭の子ほど写真が多くなりがちです。偏りチェック表を写真の締め切り直後に作り、足りない子の写真を早めに集めます。

**失敗2：名前・背番号の誤字**
卒団式の場で名前を間違えるのは、とても気まずいものです。名簿をコピーして使い、必ず別の人にも確認してもらいます。

**失敗3：BGMの扱いを後回しにする**
使いたい曲が決まっていても、使い方によっては権利の確認が必要になる場合があります。編集アプリで使える音源の利用規約を確認し、判断に迷う場合は役員・会場と相談してください。
【本人が追記：実際にBGMをどう選んだか】

**失敗4：一人で全部抱え込む**
写真の回収、名簿の確認、当日の再生など、人に頼める作業は分担します。「編集だけは自分、それ以外は役員と分担」と決めておくと楽になります。

**失敗5：完成したムービーをそのままSNSに上げる**
子どもたちの顔と名前が入った動画です。共有する範囲は、事前に役員会で決めておきましょう。

### ⑥ まとめ

卒団ムービーは、編集の技術よりも段取りで決まります。

1. 方針を決める
2. 依頼文で写真を集める
3. 構成表と偏りチェック表で、全員が主役になるようにする
4. 仮編集から初稿へ
5. 確認・再生テスト・予備の用意

この順番で進めれば、編集経験がなくても、余裕を持って卒団式を迎えやすくなります。

子どもたちが最後に見るムービーが、「このチームでよかった」と思える時間になりますように。
