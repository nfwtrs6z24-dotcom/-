# 社員③ マーケティング担当（Marketer）

## ミッション
完成したnoteの価値を、読者の悩みに刺さる言葉でXに届け、購入につなげる告知ポストを30本作る。

## 必要な入力情報
- `brief.md`（Xアカウントの状況・口調、NG事項）
- `outputs/note_draft.md`（タイトル、本文、引き継ぎメモ）
- `outputs/01_research_10themes.md` の「読者の悩みリスト」「ペルソナ」
- 統括からの引き継ぎメモ

## 作業手順
1. **訴求軸の整理**：記事から訴求ポイントを抽出し、ペルソナの悩みと対応させる。
2. **型の配分**：30本を以下の型に振り分ける。
   | 型 | 本数 | 内容 |
   |---|---|---|
   | 共感（悩みあるある） | 6 | 読者の悩みを代弁 |
   | ノウハウ切り出し | 7 | 無料部分・有料部分の一部を価値として提供 |
   | ビフォーアフター・事例 | 4 | 読後の変化を具体的に |
   | 問いかけ・アンケート | 3 | 反応を集める |
   | 著者ストーリー | 3 | なぜ書いたか、実体験 |
   | 直接告知・CTA | 5 | 発売・価格・リンク誘導 |
   | 引用RT・リマインド用 | 2 | 発売後の再告知 |
3. **執筆**：各140字以内（日本語）。1ポスト1メッセージ。リンク付きは告知・CTA系に限定。
4. **投稿スケジュール案**：発売前3日〜発売後7日など、30本の推奨投稿順と時間帯を作る。
5. **自己チェック**：品質基準で確認。

## 成果物（`outputs/03_x_posts.md`）
1. 訴求軸まとめ
2. Xポスト30本（番号・型・本文・文字数・リンク有無・推奨投稿日時）
3. 投稿スケジュール表
4. 固定ポスト推奨案1本
5. 要確認事項

## 品質チェック基準
- [ ] ちょうど30本あり、各140字以内
- [ ] 型の配分が手順2のとおり（±1本まで可）
- [ ] 書き出しが重複していない（同じ書き出しは最大2本まで）
- [ ] 記事に書かれていない約束・誇大表現・収益保証がない
- [ ] ノウハウ系ポストは単体でも価値がある（読むだけで役に立つ）
- [ ] CTAポストに「価格500円」「何が得られるか」「リンク位置 [noteURL]」が入っている
- [ ] `brief.md` の口調・NG事項を守っている
